Cybersecurity Learning Tool - Final Year Project

  • Final year project
  • In progress

As part of my degree, I am required to complete a more substantial project over the course of my final year, and so this is that project. As of now it is still a work in progress, and so I can't share much, but here's a snippet from the original project description to give a rough idea:

Educational Tool for Learning Security Protocols

In this project the student will develop a visual and interactive educational simulator to learn security protocols, focussing on the handshake stage. In security protocols two parties try to establish their identities (one-sidedly or mutually), negotiate cryptographic tools to be used, and establish session keys.

Deliverables:

  • A functional visual simulator for simple protocols
  • Visual representation of the communicating parties and exchanged messages
  • Step-by-step, pause, replay and reset controls
  • Visualisation of authentication, key exchange and session-key establishment
  • Ability to inspect individual handshake messages
  • Explanations of the purpose of each handshake stage
  • Software architecture, testing and technical documentation
  • Basic usability evaluation

Riff - Music Version Control

  • Python
  • Microsoft Intern Hackathon

I completed this project during my internship at Microsoft as part of their Intern Hackathon. I was part of a team of three people (myself included), and my main responsibility was to create the working demo that you see displayed below. We created "Riff", a version control tool built for musicians, producers, and songwriters to enable better collaboration. We addressed the problem of online music collaboration today being messy and unorganised and aimed to solve this problem. The tool uses a Git-like syntax (the working title of the project was "Git for musicians") which will feel familiar to technical users. We also had plans to create a UI version later to be more accommodating to non-technical users.

Marketplace Web Application

  • Java
  • Spring Boot
  • Thymeleaf
  • SQL

This is a simple web application to simulate an online marketplace (specifically, a fake online coffee shop). It was completed as part of a university course on web development. The app distinguishes two types of users:

  1. User: users can explore the homepage, inspect item descriptions, add items to their basket, checkout, and view their orders.
  2. Admin: admins can do all the same tasks as users while also being able to add/remove/edit item descriptions, prices, etc. and update the status of orders.

This project reinforced my skills in basic web development while also exposing me to more advanced topics such as programming with frameworks such as Spring Boot, Thymeleaf, and using databases from within Java code.

Sorting Algorithms Visualiser

  • Java

It is inevitable that every student of computer science will eventually have to study data structures and algorithms, and more specifically, sorting algorithms.

The goal of this project was to create a tool to aid in the learning of these algorithms, and gain a more intuitive understanding of how they work. It's one thing to read about an algorithm and its various steps to arriving at a solution, but to be able to see each of these steps and visualise them in real time was greatly beneficial to my understanding of them.

I chose to implement a wide range of algorithms of varying time and space complexities including:

  • Bubble Sort
  • Selection Sort
  • Shell Sort
  • Insertion Sort

I also added some other less common but interesting algorithms such as sleep sort and bogosort, and I plan on implementing more algorithms in the future.
