Sorting Algorithm Visualiser

It is inevitable that every student of computer science will eventually have to study data structures and algorithms, and more specifically, sorting algorithms.

The goal of this project was to create a tool to aid in the learning of these algorithms, and gain a more intuitive understanding of how they work. It's one thing to read about an algorithm and its various steps to arriving at a solution, but to be able to see each of these steps and visualise them in real time was greatly beneficial to my understanding of them.

I chose to implement a wide range of algorithms of varying time and space complexities inlcuding:

  • Bubble Sort
  • Selection Sort
  • Shell Sort
  • Insertion Sort

I also added some other less common but interesting algorithms such as sleep sort and bogosort, and I plan on implementing more algorithms in the future.

As with all of my projects, you can keep up to date on my progress with them on GitHub: Sorting Algorithms Visualiser - GitHub Repository

Weather App

This project serves as a demonstration of my skills in web design. It was made entirely using HTML, CSS, and JavaScript.

As you can see, there is a text box where you can enter the name of a City/Country. Clicking the search icon gives some basic weather information about that location. It uses a weather API to fetch data so that it can be displayed to the user. Additionally, there is functionality to switch whether the temperature is displayed in degrees Celsius or Fahrenheit by clicking the associated text.

From this project I learned some fundamental JavaScript concepts, CSS animations, and how to fetch data from an API
